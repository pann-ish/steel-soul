| | |
|---|---|

| 💥 **极必杀 & 奥义** | 用币解锁，耗尽能量放出全屏动画大招 |

## 🕹️ 怎么玩 How to Play

1. 用手机打开 **https://pann-ish.github.io/steel-soul/**
2. 点封面进入，选机体，选「闯关」或「训练场」
3. 左边摇杆移动，右边按键普攻、必杀、极必杀、奥义
4. Boss 头上出现重击提示时，按 **躲避** 打出反击！

> 💡 想装成 App：iPhone 用 Safari 点「分享 → 添加到主屏幕」，Android 点「⋮ → 安装应用」。
